routes cannot return data today:

| Route id(s)                                                          | Backing relation                                                       | Observed                                                                                                                | Effect                                                                                                  |
| -------------------------------------------------------------------- | ---------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `predictions.events`, `predictions.event`, `predictions.cross_venue` | `prediction_events_mat` (materialized view)                            | **Does not exist**: `supabase/migrations/20261026180000_prediction_events_mat.sql` is hand-applied and has not been run | 503 `not_available` ("being provisioned"); `predictions.categories` returns event counts as unavailable |
| `patents.grants`, `patents.momentum`, `patents.company_monthly`      | `eyes_patents` (read by `eyes_patent_momentum`, `eyes_patent_monthly`) | **0 rows**                                                                                                              | Empty data with an "ingest pending" coverage note; the composite's patents section is always null       |
| `night_lights.regions`, `night_lights.region`                        | `eyes_night_lights`, `eyes_regions`                                    | **0 rows**                                                                                                              | Empty data                                                                                              |

Recommendation: either run the patent and night-lights ingests and apply the events view, or move these eight
routes to `docs/ezana-api-backlog.md` until they return data, as the registry header requires ("the API
documents only what it serves"). This audit does not change them, because removing live routes is a product
decision.
