# 03 · Cross-dataset opportunity matrix

Pairs and combinations, the join that is valid today, the hypothesis worth testing, and what stops it.
"Overlap" names an existing endpoint that already answers part of the question, so it is extended rather than
duplicated.

| Combination                        | Valid join                                       | Candidate hypothesis                                                    | Status today                                                                                      | Overlap with existing routes                                                                  |
| ---------------------------------- | ------------------------------------------------ | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Contracts x own history            | ticker (resolved), fiscal year                   | Unusual obligation years mark changes in government business            | **Live**: `/v1/alpha/procurement-acceleration`                                                    | Extends `/v1/contracts/companies/{ticker}` (raw by year) with calibrated unusualness          |
| Contracts x sector peers           | ticker to sector (static map)                    | Growth beyond the sector's own move is company-specific                 | **Live** inside procurement acceleration (`excess_arc_growth`)                                    | -                                                                                             |
| 13F x sector                       | CUSIP/ticker, quarter; filer CIK across quarters | Holder breadth changes that diverge from the sector mark repositioning  | Blocked: 13F parse coverage (9.4% of Q3)                                                          | `/v1/institutional/confluence`, `/v1/institutional/whale-moves` (top moves, no peer baseline) |
| Form 4 x 13F                       | issuer ticker, same quarter                      | Insider open-market direction agreeing with 13F change strengthens both | Blocked: 13F coverage, and Form 4 has 54 days                                                     | `/v1/cross/composite/{ticker}` counts both as stated rules                                    |

| Sanctions x companies              | verified counterparty or geography               | Direct exposure changes risk                                            | Blocked: no verified company mapping                                                              | `/v1/sanctions/...`                                                                           |

## Join rules enforced

- Never join on name similarity alone. Contracts use the resolved ticker; lobbying statistics must use
  `verified` mappings only; 13F joins on CUSIP and filer CIK.
- Every time join uses the date the information became public (13F `first_filed_at`, Form 4 `filed_at`,
  congressional `disclosure_date`, fiscal-year reporting window), never the economic date.
