# Sonar research modes: drafted evaluation questions for review

These 150 questions were drafted for the research-mode classifier's evaluation suite
(`scripts/fixtures/sonar-mode-eval/drafted.json`). None is reviewed yet, so the suite
prints their numbers but does not fail on them.

**To review:** mark each row in the _Approved?_ column (yes, or the mode you would choose).
Then set `"reviewed": true` on the approved rows in `drafted.json` (and correct `"mode"`
where you disagree). Once rows are reviewed, `npm run test:sonar-research-mode` gates on them:
quick questions offered deep at most 5%, standard agreement at least 80%.

The _Classifier_ column is what the classifier said when this file was generated
(mode / confidence, with Go deeper where borderline). It is there to show disagreements, not to
argue for the label.

The questions I was least sure about are marked **(unsure)** in the rationale.
